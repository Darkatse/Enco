# Enco 路线图

路线图只写尚未完成的阶段：目标、验收与里程碑的顺序。设计见[设计文档](design/README.md)，文中的"某某专题"指其中的专题。已完成的阶段（P0–P3、Session 委派）与里程碑（M1–M43）的验收记录在 git 历史中。

## 计划与验收

- **计划**：阶段开始时，路线图写目标与里程碑的顺序。每个里程碑一份计划，放在 [plan/](plan/)，包含目标、对齐的判断、范围、设计、验收与待定。里程碑开始时计划定稿；新的 WIT、数据库模式这类契约先写在计划里，实现之后以代码为准。实现中的偏离与手动核对也写进计划。
- **完成条件**：
  - 验收场景通过，`cargo xtask check` 通过；
  - 会改变 Agent 行为的里程碑运行评测（[evals/README.md](../evals/README.md)）；
  - 逐路径审阅之后，由主人从第一性原理审核通过；偏离计划的决定已说明理由，并得到主人确认；
  - 里程碑结束时系统完整可用，过渡形态只存在于代码中。
- **验收之后**：
  - 对齐的判断中长期有效的，提炼进设计文档；
  - 返工过的地方写进 [LESSONS.md](../LESSONS.md)；
  - 仍有效的暂不实现，移入「之后」或后续计划；
  - 计划原文与真实运行数据移入本地的 `.archived_docs/plan/`，路线图删去这个里程碑。

## P4 Space v1

**拓扑**：VPS 与 Homelab 是常驻的完整节点，另一个地区的 VPS 是只运行控制平面的见证者，三者投票；Mac 与以后的手机是 learner，可能断网。

**判断**：2026-11-09 与主人对齐，各自落在对应里程碑的计划里，验收时提炼进多节点专题。

- **三类事实**：跨节点的只有控制平面的记录、单写者的流与按哈希寻址的内容。可变事实放在检查它的不变式所在之处。
- **续接**：漫游、强制接管与崩溃恢复都是"封口，再从 Log 续上"，只差封口点由谁决定。
  - 封口写进新 epoch 的第一条；先追平，再推进 Binding；Run 跨越漫游继续。
  - 漫游按登记的准入检查目标，接管不检查。
- **名字**：根 Session 由控制平面分配，在 Space 内唯一；子 Session 由父的持有者分配，所以委派不需要控制平面。节点以空库加入。
- **代码**：代际只来自登记；出厂代码与原生能力按宿主的内容标识。意图在控制平面，运行与健康按节点记录。
- **时间**：只有渠道用租约，定时跟着 Session 走。
- **复制**：投递与复制都是跟随 Log 游标的壳。Inbox 不复制，跨节点的输入经 outbox。复制的范围就是读取的范围，所以不需要 Brief。
- **少数派**：断网的节点继续执行持有的 Session，也可以委派；不能新建根 Session、漫游、接管或登记。
- **载体**：iroh，中继自建，地址来自成员表；Tailscale 可选。
- **验证**：协议核心是纯状态机，由 Stateright 穷举；Turmoil 注入分区、崩溃与时钟漂移；不变式从各节点的 Log 检查。
- **升级**：从 M44 起升级不丢记录；Space 版本定案之后不能降级。

**验收**（**验证第二个原始动机**）：

- 任务中途漫游到另一个节点，Run 继续；漫游过程中断开连接，不出现双 Round（M46）。
- VPS 失联时，主人在 Homelab 确认接管 `main` 并继续对话；VPS 回来后立即停下，它没有复制出去的尾部作为一条输入进入主线（M46）。
- 杀掉 VPS 后，Telegram 的租约在 TTL + ε 内转移到 Homelab，全程不存在两个轮询者（M48）。
- Mac 断网时继续执行它持有的 Session 并委派；新建根 Session、漫游与登记都明确失败（M46、M48）。
- 在一个节点上登记的修改在其余节点生效，各节点分别试用与回退；落后于最新登记的 home 不能登记（M45）。
- VPS 上的 Session 使用 Mac 工作目录中的文件与 shell；在 Mac 写入的记忆，在 VPS 上可以召回，更正与遗忘在各节点都生效（M47）。
- Stateright 穷举无反例，漫游、接管与重复输入都可达；Turmoil 中的故障不违反任何不变式（M46、M48）。

**里程碑**：

| 里程碑 | 一句话 |
|---|---|
| M44 事实归位 | 只有一个节点时，就把每份事实放到它在 Space 中的位置：代际只来自登记，意图与运行分开；Session 是创建记录与自己 Log 的函数；定时归 Session；宿主一步迁移库 |
| M45 结对与复制 | iroh 连接与配对；协议核心与控制平面（openraft，先只有创始节点投票）；内容按哈希拉取；Log 复制；各节点跟随期望状态；Space 版本 |
| M46 漫游与接管 | 封口、追平、推进 Binding、到达；强制接管，分叉作为输入进入主线；跨节点的输入经 outbox |
| M47 invoke 与记忆 | 远程能力，工作目录可以在别的节点；记忆有持有者，写入经 invoke |
| M48 三个投票者与渠道租约 | Homelab 与见证者加入投票；渠道租约与故障转移；渠道输入的 ID 由更新键决定 |

## 其余阶段

**P5 手机节点**：learner 节点；进入后台前自动漫游回常驻节点；设备能力导出；跨节点委派。
验收：iOS 应用在任务中被切到后台后，任务在 VPS 上继续；VPS 上的 Session 可以调用手机相机。

**P6 CP 加固**：更大规模的 Stateright 检查与长时间的 Turmoil 运行；在真实网络上演练分区、休眠与唤醒、租约期间 leader 变更与旧节点复活。

**脚本调用**（工具多到逐个调用的代价明显时实施）：
- **内容**：宿主的脚本沙箱（QuickJS 编译为 Wasm）；嵌套调用逐个分派与记录；脚本内的 `capability_search`。
- **验收**：
  - 一段脚本并行调用多个工具，模型只看到脚本的输出；
  - 未披露也未被搜索返回的能力被拒绝；
  - 被策略点拦下的嵌套调用在脚本中表现为失败；
  - 脚本在一次副作用调用之后中断，结算列出该调用及其结局，脚本不重跑。

**插件生态**：
- **内容**：
  - 跨插件导入与宿主转发；
  - 外来插件的安装与更新，采纳时由主人确认扩大的权限；
  - 宿主同时链接 `enco:plugin` 的历史版本，`enco:plugin` 1.0，`enco-sdk` 按 semver 发布；
  - 采纳外来修订时检查依赖的许可证与安全公告。这项检查需要联网，放在采纳流程与 CI 中。
- **验收**：
  - 一个第三方插件被另一个插件导入；
  - 回退被导入的插件后，依赖它的插件退出快照，原因对模型可见；
  - 扩大导入的更新停在待确认状态；
  - 宿主升级 WIT 主版本后，未重建的第三方插件照常运行。

**Windows 节点**（需要时实施）：
- **内容**：本地端点改用只限当前用户的命名管道；shell 使用 PowerShell 7，输出按 UTF-8 解码；守护进程响应控制台关闭与系统关机；CI 增加 Windows runner。参与 Space 之前，补上计入休眠时间的时钟。
- **验收**：`cargo xtask check` 在 Windows 上通过；CLI 经命名管道与守护进程对话，其他用户无法连接；`shell_exec` 正确返回中文输出。
