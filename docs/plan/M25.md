# M25 手册

> 路线图 P2 的第 7 个里程碑。计划的生命周期见 spec 09 §5。

## 目标

P2 主验收的前提：Agent 全程只读手册和插件源码，不读宿主源码，就能修好一个插件（§7）。

## 范围

- 内核与 SDK 的 API.md（§7.4），两者同时启用 `missing_docs`。
- 每个代际的运行时手册（§7.5）：来自 `tools.list` 的工具、来自 `describe` 的配置项（由 `config-schema` 生成）与凭证声明，以及上限常量。README 生成区随之更新。
- `manual_read` 与 `capability_search` 工具；composer 的目录披露使用它们。

## 规格

- 02：`missing_docs` 与 API.md 的生成。
- 05：`manual_read`、`capability_search` 与目录披露。
- 07：运行时手册的生成。

## 验收

- `adapter-drift` 经正式路径通过，包括"只读手册"这一项：Log 中没有任何读取宿主源码的工具调用。
- `build-from-spec` 通过：新建的工具插件在同一次任务的后续 Round 中被用上，运行时手册随代际生效。
- `many-tools` 跑出基线。
- 已有题目按 spec 13 的规则不退化。
