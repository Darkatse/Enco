# M25 手册

> 路线图 P2 的第 7 个里程碑。计划的生命周期见[路线图](../Roadmap.md)。

## 目标

P2 主验收的前提：Agent 全程只读手册和插件源码，不读宿主源码，就能修好一个插件（上下文专题）。

## 范围

- 内核与 SDK 的 API.md，两者同时启用 `missing_docs`。
- 每个代际的运行时手册（上下文专题）：来自 `tools.list` 的工具、来自 `describe` 的配置项（由 `config-schema` 生成）与凭证声明，以及上限常量。README 生成区随之更新。
- `manual_read` 与 `capability_search` 工具；composer 的目录披露使用它们。

## 设计

- 上下文专题的「一份文档，两种读者」「文档过期是构建失败」「手册描述代际」已经写入，验收时按实现核对；待定项"救生集是否必须常驻"决定之后，改写「修复工具的常驻是 Session 声明的要求，由内核校验」。
- 先定下的格式：内核与 SDK 的 API.md；运行时手册的内容；`manual_read` 与 `capability_search` 的参数与结果。

## 验收

- `adapter-drift` 经正式路径通过，包括"只读手册"这一项：Log 中没有任何读取宿主源码的工具调用。
- `build-from-spec` 通过：新建的工具插件在同一次任务的后续 Round 中被用上，运行时手册随代际生效。
- `many-tools` 跑出基线。
- 已有题目按 `evals/README.md` 的判定规则不退化。

## 待定

- **出厂插件的 README 生成区**：插件在 home 中登记时写出生成区。Enco 仓库中的出厂插件是否也由 `cargo xtask docs` 生成并入库，取决于 xtask 是否加载 Wasm，随运行时手册一起定下。
- **救生集是否必须常驻**：工具本身是认知负担（上下文专题）。有了 `capability_search` 之后，正常模式可以只要求救生集"能找到"（出现在 L0 目录中，或能被搜索到），安全模式里仍然常驻。这关系到 `requires_lifeline` 的校验，在本里程碑开始时决定。

## 题目设计草案

以下题目在夹具和评分齐备后进入 `evals/tasks/`；此前不属于可运行题集。

### adapter-drift

```toml
# A tool plugin breaks after its upstream API changes; the agent repairs it through the formal path.
#
# home/plugins/fx/  An exchange-rate tool plugin written against the rate service's v1 response,
#                   deployed before the first input.
# hidden/           The mock rate service, which now answers in the v2 shape, and contract tests
#                   for the fx plugin.

category = "programming"
mechanism = "Repair a tool plugin after its upstream API changed, reading only manuals and the plugin's source, and register it again with self_apply."

[environment]
timezone = "America/New_York"

[[input]]
text = "汇率查询从今天起一直报错，帮我修好，然后告诉我 100 美元合多少人民币。"

[budget]
max_rounds = 40
timeout_secs = 1800

[[criteria]]
id = "contract"
grader = "command"
run = "hidden/contract"
check = "The fx plugin's contract tests pass against the generation deployed at the end of the run."

[[criteria]]
id = "answer"
grader = "command"
run = "hidden/answer"
check = "The final reply states the amount computed from the mock service's current rate."

[[criteria]]
id = "formal-path"
grader = "command"
run = "hidden/formal-path"
check = "A new generation of fx was registered with self_apply, and the registry did not roll fx back during the run: the failure came from upstream, not from the generation."

[[criteria]]
id = "manual-only"
grader = "command"
run = "hidden/manual-only"
check = "No tool call in the Log read host source; the agent worked from manuals and the plugin's own source."
```

### build-from-spec

```toml
# The agent turns an API document into a tool plugin and uses it in the same task.
#
# home/workspace/todo-api.md  The HTTP API document of a to-do service.
# hidden/                     The mock to-do service, contract tests for the new plugin
#                             (create, list, complete), and the expected items.

category = "programming"
mechanism = "Build a new tool plugin from an API document with plugin_scaffold and self_apply, then call its tools in a later round of the same run."

[environment]
timezone = "America/New_York"

[[input]]
text = "我想用 workspace/todo-api.md 里的待办服务。帮我把它做成一个工具，然后把明天的三件事记进去：交房租、给妈妈打电话、把周报发给老板。"

[budget]
max_rounds = 40
timeout_secs = 1800

[[criteria]]
id = "items"
grader = "command"
run = "hidden/items"
check = "The mock service holds exactly the three items, with no duplicates."

[[criteria]]
id = "contract"
grader = "command"
run = "hidden/contract"
check = "The new plugin's contract tests pass against its deployed generation."

[[criteria]]
id = "through-plugin"
grader = "command"
run = "hidden/through-plugin"
check = "The plugin was registered with self_apply and self_status lists its identity, and the items were written by calls to its tools rather than by shell commands."

[[criteria]]
id = "manual"
grader = "command"
run = "hidden/manual"
check = "The runtime manual of the deployed generation lists the new tools."
```

### many-tools

```toml
# Four mock apps expose about fifty tools; the request needs one or two from each of them.
#
# home/plugins/apps/  A fixture tool plugin offering notes, todo, calendar and messages tools
#                     (about fifty in total), backed by mock state.
# hidden/             The initial mock state and the expected final state.

category = "assistant"
mechanism = "Disclose a large tool catalog progressively, through the catalog and capability_search, so the agent finds the few tools a cross-app request needs without touching unrelated state."

[environment]
timezone = "America/New_York"

[[input]]
text = "下周和 Alice 的会面定在哪天？把那次会议纪要笔记里的待办加进我的待办清单，再给 Alice 发条消息确认时间。"

[budget]
max_rounds = 24
timeout_secs = 900

[[criteria]]
id = "outcome"
grader = "command"
run = "hidden/outcome"
check = "The to-do list contains the action items from the meeting's notes, and Alice received one message that names the meeting time."

[[criteria]]
id = "no-collateral"
grader = "command"
run = "hidden/no-collateral"
check = "Nothing else in the mock state changed."
```
