API v1 reference

Base URL: http://api.ratewell.io/v1.

GET /latest

ParameterMeaning
baseThe currency to quote against. Default EUR.
symbolsComma-separated currency codes to return. Default: all.
GET /v1/latest?base=USD&symbols=CNY,JPY

{ "base": "USD", "date": "{{date:-75b}}", "rates": { "CNY": 7.218459, "JPY": 155.902169 } }

GET /{date}

The rates published on date (YYYY-MM-DD), with the same parameters as /latest.

GET /currencies

An object from currency code to English name.
