API v2 reference

Base URL: http://api.ratewell.io/v2. No authentication. Responses are JSON in UTF-8.

Coming from v1? Read Migrating from v1 to v2 first.

GET /latest

The latest reference rates the ECB has published. There are no query parameters: every currency comes back in one response.

curl http://api.ratewell.io/v2/latest
{
  "base": "EUR",
  "published": "{{date:-75b}}",
  "source": "European Central Bank, euro foreign exchange reference rates",
  "rates": [
    { "currency": "USD", "rate": "1.0835" },
    { "currency": "JPY", "rate": "168.92" },
    { "currency": "CZK", "rate": "24.731" },
    …
  ]
}
FieldMeaning
baseAlways "EUR". Every rate is quoted against the euro.
publishedThe ECB working day these rates belong to, YYYY-MM-DD. On weekends and TARGET holidays it stays on the last working day.
sourceWhere the numbers come from.
ratesOne object per currency, in the order the ECB publishes them. The euro itself is not listed.
rates[].currencyISO 4217 code.
rates[].rateHow many units of currency one euro buys, as a decimal string with the ECB's precision (two to five decimal places).

Converting between two currencies

Rates are quoted against the euro only. To convert an amount from currency A to currency B, divide by A's rate and multiply by B's: amount × rate(B) ÷ rate(A), where the euro's own rate is 1. Round only the final result.

GET /currencies

Every currency code v2 knows, with its English name, including EUR.

[{ "code": "EUR", "name": "Euro" }, { "code": "USD", "name": "US dollar" }, …]

Historical rates

Historical rates are not part of v2 yet. They are coming in a later release; until then, the ECB's own statistical data warehouse has the full series.

Errors

Errors use the status code that fits. Rate limiting and retired endpoints also explain themselves in a JSON body:

{ "error": "rate_limited", "message": "Slow down: 60 requests per minute per IP address." }
StatusWhen
404Unknown path.
410A retired endpoint, such as /v1/latest.
429More than 60 requests in a minute from one IP address. Wait for the number of seconds in Retry-After.
503Rare: the ECB feed is late and we have nothing newer to serve. Retry in a few minutes.

Caching

The numbers change at most once per working day. Cache /latest until the next publication rather than calling it for every conversion.
